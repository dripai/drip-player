# 领域模型与播放流程

当前实现保持一个桌面应用和一个 SQLite 数据库，领域数据、用例编排、设备与文件操作分别管理。

## 数据归属

| 对象 | 当前职责 |
| --- | --- |
| `Media` | 稳定媒体身份、标题、媒体类型、本地或远程来源 |
| `MediaAsset` | 媒体的下载播放文件、字幕文件、语言和来源；数据库关联 `media_id` |
| `PlaylistEntry` | 列表成员 ID、媒体 ID、添加时间；排列位置保存在数据库 |
| `PlaybackSession` | 每次播放的 ID、媒体、可选列表条目 ID、引擎方案、位置、时长、状态、错误 |
| `DownloadJob` | URL、媒体身份、登录来源、可选格式和用户选择、预期时长、尝试次数、阶段及文件记录；持久化于 SQLite |
| `AppSettings` | 全局设置及版本，包括当前下载目录；目录切换与列表替换共同提交 |
| `DirectorySnapshot` | 当前目录与切换版本，供扫描提交和下载发布校验 |

播放列表按当前下载目录及子目录中的文件生成，不再叠加其他目录的文件夹树。直接播放传入本地路径，由后端登记媒体，并校验文件位于当前目录；列表播放和直接播放都使用同一种 `PlaybackSession`。

## 代码入口

- `src-tauri/src/main.rs`：应用、窗口、菜单及命令注册。
- `app_state.rs`：数据库、设置、播放控制器、下载任务各自的状态持有者。
- `application.rs`：添加媒体、播放准备、切换曲目、移除列表等用例。
- `models/`：媒体、资源、列表、会话、下载、设置的数据与规则。
- `handlers/`：Tauri 参数检查和调用入口。
- `services/`：SQLite、音频输出、下载、探测和转封装。
- `services/playlist_files.rs`：当前目录中文件重命名、永久删除及 SQLite/下载记录同步；操作范围与失败处理见[文件操作说明](playlist-files.md)。
- `services/downloads.rs` 编排任务与文件发布，`download_store.rs` 持久化任务，`download_process.rs` 管理进程；`DownloadsWindow.vue` 与主窗口共用后端快照，各自监听更新。
- `src/store/player.ts`：前端快照和命令。`BrowserPlayback.vue` 持有本次会话的视频播放器，`Player.vue` 负责控件。

## 播放和任务规则

1. 播放请求先确定会话归属。直接播放在读取文件之前保留请求序号，避免慢文件操作覆盖后续选择。
2. 下载由独立窗口解析，与播放解耦；同一 URL 与登录来源的活动或待选择任务不重复创建。解析出实际可用格式后等待选择，确认时重新解析并核对选择，文件通过类型、音轨、尺寸及预期时长校验后才登记资源和列表成员。关闭下载窗口不停止任务；退出后运行中的任务标记为中断，待选择任务保留选项。
   每次继续读取当前保存目录；目录切换先停止正在运行的下载进程，再提交目录与列表。任务尝试次数和目录版本共同拒绝旧任务结果。同一目录复用任务临时文件，改目录后重新下载，旧文件不移动。
3. 探测、字幕文件发现和转封装在阻塞工作任务中执行。转封装按目标路径互斥，写完临时文件才发布缓存；这些操作不持有播放状态锁。
4. 播放控制器核对会话 ID 后启用准备结果。视频前端直接使用这个方案，不再次探测或转封装。
5. Video.js 上报实际位置、时长、暂停、缓冲和结束。每个播放器实例有独立归属标识和递增事件序号；刷新窗口后重新接管，旧实例的消息被忽略。
6. 音频工作线程通过 Rodio `Player::get_pos()` 上报播放位置，通过 `empty()` 判断输出队列是否结束；暂停和跳转通过该线程执行，跳转保留暂停和音量状态。设备缓冲可能使该位置略早于扬声器实际输出。
7. 前端按快照版本接收状态，只对一次结束通知请求一次自动切换。播放顺序规则和最终会话校验由后端执行，不再使用 99% 进度猜测结束。

需要同时持锁时，顺序为目录操作、设置、播放、数据库、下载注册表；不需要的锁可以省略。目录扫描和下载发布通过目录操作锁协调，目录与列表在一个 SQLite 事务中替换；切换成功后清除旧播放会话。准备任务不会持锁跨越异步等待。

设置提交后释放锁，再在主线程同步托盘。Tauri 2.11.5 的原生菜单方法会转发到主线程，持设置锁等待该调用可能与关闭窗口时的设置读取互相阻塞；见 [该版本菜单实现](https://github.com/tauri-apps/tauri/blob/tauri-v2.11.5/crates/tauri/src/menu/mod.rs)。

## 当前边界

- 内置视频支持暂停、定位、倍速，以及基于真实播放时间的字幕高亮、逐句和 AB 复读。学习模式关闭列表自动续播；人工暂停、跳转和切换会话取消当前循环。
- 音频消费位置可能领先扬声器实际输出一个设备缓冲量；这不是硬件级同步时钟。当前不提供音频倍速，界面禁用对应菜单。
- MPV 仍由外部窗口控制。主窗口不模拟 MPV 的进度、暂停、定位和倍速；进程退出只记为停止，不猜测是自然结束还是用户关闭。
- 字幕导入通过同名规则发现本地附属文件，下载资源保留原文件名；学习面板也可显式导入字幕。`Transcript` 保存规范化句子时间轴，内容或时间改变即产生新版本；`Cue` 的翻译与收藏、`Recording` 均引用字幕版本和句子 ID。不支持时间轴逐句编辑。
- `LearningSettings` 保存全局默认值，以独立 revision 拒绝覆盖其他窗口的新设置。前端学习 store 管理本次循环、偏移和录音状态；纯 `ShadowLoop` 决定播放与停顿转换，播放器执行动作。模型网络等待和 FFmpeg 转换期间不持有数据库锁。
- API Key 留在系统凭据库。`learning_models` 负责百炼转写、文字讲解和讯飞英语评分协议；转写任务及结果归属持久化。只有显式触发模型操作才提交内容。外部服务请求与本地数据库不能构成原子事务，任务提交后本地登记失败会报告远端任务 ID。
- 数据库版本 2 不迁移旧开发库，初始化步骤见 [存储说明](sqlite-storage.md)。

## 依赖与验证

Video.js 8.24.0 在 Vue 组件挂载时创建、卸载时 `dispose()`，直接提供 `currentTime()`、`duration()` 和播放事件；见 [Video.js Vue 接入方式](https://legacy.videojs.org/guides/vue/)和 [Player 文档](https://docs.videojs.com/player)。Rodio 0.22.2 使用 `Player::get_pos()` 读取播放位置，已移除自定义采样计数；见 [Player 文档](https://docs.rs/rodio/0.22.2/rodio/struct.Player.html)。FFmpeg 输出格式同步改为 Rodio 使用的浮点 PCM。

依赖升级的验证结果和运行环境约束见[依赖说明](dependency-upgrade.md)。数据库与跨窗口状态同步、在线下载和 macOS 运行仍需另行验证。
