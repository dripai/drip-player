# 下载与清晰度选择

1. 打开顶部下载窗口，粘贴 URL，选择登录来源，点击“解析”。
2. 在任务行中选择站点实际返回的清晰度，点击“下载”。视频默认选中最高可用档位；选中选项本身不会开始下载。音频资源可保留原格式，只有主动选择“仅音频 · MP3”才会转换。
3. 需要账号权限时，先在所选浏览器登录，再点击任务行的“重新解析”。可选择 Chrome、Edge、Firefox 或“不使用登录”；解析与下载使用同一来源，读取失败明确报错，不自动切换浏览器。
4. 关闭下载窗口后任务继续运行。退出应用后，待选择的任务保留选项；运行中的任务恢复为已中断。继续下载使用当前设置目录，并重新核对所选清晰度是否仍可用；不可用时返回选择状态，不自动降档。
5. 已完成任务可点击“重新下载”创建新任务，用于重新选择清晰度或修复此前错误下载的音频。已有媒体文件不会被覆盖或删除，新任务不直接复用旧任务的完成文件。
6. 右下角“清理历史记录”删除所有未在执行的任务记录，包括已完成、失败、取消、中断、待选择和待恢复记录；保留正在解析、下载、校验及保存的任务。只修改任务记录，不删除或移动已下载文件、字幕和未完成的临时文件，不改变播放列表。清理后原任务不能继续，重新提交链接会创建新任务。

历史清理与任务启动、取消及发布共用目录操作锁，按执行时的最新状态筛选，在一个 SQLite 事务中删除记录；提交成功后清除相应运行时状态。数据库失败保留全部记录，迟到的任务回调不重建已清理记录。此操作不执行文件恢复、文件删除或目录扫描。

列表仅显示当前来源实际能获取的格式，不列出账号无法获取的分辨率。站点登录、会员、区域及浏览器 Cookie 读取能力仍决定可用范围。整季链接返回多条内容时，请改用单集链接。

文件名组合去重后的系列名、季名或片名、分集名，例如 `理查德·柯蒂斯三部曲 - 时空恋旅人 - 正片.mp4`。普通视频保留原始标题。文件扩展名由实际下载和合并结果决定，不统一强转 MP4 或 MP3。

成品直接写到当前设置目录，例如 `D:/Media/百万英镑.mp4`，不再创建媒体 ID、任务 ID 两层成品目录。字幕保留在媒体旁边。名称已被媒体、字幕或目录占用时，媒体和字幕一起改为 `百万英镑 (1).mp4`、`百万英镑 (1).zh.srt`，不会覆盖已有文件。原先下载的文件保持原位，递归扫描仍能找到。

同一分辨率优先选完整内容的 H.264 视频和 AAC 音轨，再按站点的格式偏好选择；不因为编码偏好降低分辨率，也不优先选择 H.264 试看内容。选项显示已知编码，例如 `1080p · H.264`、`1080p · HEVC`；站点未给出编码时不猜测。没有 H.264 的档位保留原编码，下载过程不会偷偷转码。

下载完成后先进入“校验中”：

- ffprobe 检查实际音视频类型、所需音轨、可核对的画面尺寸和时长。
- 对站点提供的时长允许 2% 的差异，容差最小 2 秒、最大 30 秒。明显不符时报告实际时长，任务失败，不发布到播放列表；未通过校验的临时成品会被清理，避免重试时误用。
- 站点给出的“480p”等清晰度档位可能包含裁剪画面。只有同时提供宽、高时才比较实际尺寸，单独的档位高度不会被当作精确画面尺寸。
- 站点已经标明只提供部分时长的格式会禁用。未提供完整时长，或将片段时长本身标作完整时长时，无法只靠时长判断是否试看。

格式选项、登录来源标识、用户选择和预期时长保存在 SQLite，不保存 Cookie 或临时媒体直链。临时目录记录下载方案的摘要；同一目录和方案可复用临时文件，格式或登录来源变化时重建该任务的临时目录。切换保存目录继续沿用当前目录规则，不移动旧目录文件。

发布前将每个媒体、字幕文件的原名、目标名和文件版本写入任务日志，再以禁止覆盖的方式逐个移动。全部移动成功后，资源、播放列表和任务完成状态在同一 SQLite 事务中提交。移动或提交失败时按日志恢复；启动时也会恢复未提交的发布。文件被外部修改、恢复失败或日志缺失会明确报错。方案标记 `.shadow-download-plan` 留在 `downloading/<任务 ID>` 临时区，不发布到成品目录。

H.264、HEVC、AV1 的 MP4 进入内嵌播放器；HEVC 不再被提前分流到 MPV。实际解码由 WebView 和系统提供，失败时显示解码错误，不安装外部程序或自动转换整个文件。Windows 上 HEVC 的系统条件见[微软官方说明](https://learn.microsoft.com/en-us/troubleshoot/microsoft-edge/development/video-playback-issues)。缺少 ffprobe 或媒体探测失败直接报错，不按扩展名改走 MPV。

实现使用 [yt-dlp 2026.08.19 的格式选择](https://github.com/yt-dlp/yt-dlp/tree/2026.08.19#format-selection)、[输出元数据](https://github.com/yt-dlp/yt-dlp/tree/2026.08.19#output-template)和 [ffprobe](https://ffmpeg.org/ffprobe.html)，未新增第三方依赖。B 站字段处理依据[对应版本的解析器](https://github.com/yt-dlp/yt-dlp/blob/2026.08.19/yt_dlp/extractor/bilibili.py)。

Windows 验证使用 yt-dlp 2026.08.19、FFmpeg/ffprobe 8.1.1：真实工具读取本地 HTTP 的 360p/720p HLS，选择 360p 后输出带音轨的 360p 视频；显式选择 MP3 的转换也已验证。SQLite 测试覆盖等待选择、重启、改目录、过期选择和格式失效，文件校验测试覆盖错误类型、画面尺寸、封面音频及短片段。界面使用模拟 Tauri IPC 检查选择、重新解析、重新下载、跨窗口目录变化、主题及窄窗口布局。

本机公开访问 `ss44972` 的实测结果为 H.264/AAC MP4，画面 854×356，时长约 360 秒，元数据时长 7403 秒；该差异会触发时长校验失败。浏览器登录后的高清完整内容、原生窗口点击及其他桌面系统尚未实测。

2026-09-11：使用本机已有的 `百万英镑.mp4`（HEVC/AAC、1920×1080、5096.45 秒）验证后端选择内嵌播放路径；Edge 152.0.4191.66 在实际 Vue/Video.js 页面中解码开头、120 秒、中段和结尾，完成跳转、暂停和 1.5 倍速设置。界面测试模拟 Tauri IPC，同时验证编码标签和解码失败提示；没有生成新的在线下载记录。本机安装了 HEVC 扩展 2.5.33.0。这不代表所有设备都具备 HEVC 解码能力，也不等同于 Tauri 原生窗口验证。存储测试覆盖平铺文件、字幕同名避让、禁止覆盖、部分移动后重启恢复、文件占用、外部修改与 SQLite 提交失败回滚。
