# 学习设置方案

当前已实现：独立设置窗口、跟随主题的自定义标题栏，以及外观、界面语言、关闭到托盘设置。以下学习设置和模型调用均为待实现方案。

播放列表、媒体资料和通用设置已改为 SQLite 保存，不导入旧 JSON 或浏览器数据。具体边界见 [SQLite 存储说明](sqlite-storage.md)。

## 设置与播放器的分工

右键菜单保持“刷新、设置”。设置窗口按以下五组组织，录音参数放在这里。

| 分组 | 设置窗口中的内容 | 播放器中的操作 |
| --- | --- | --- |
| 通用 | 外观、界面语言、关闭到托盘 | 保留现有快捷操作 |
| 模型 | 文字讲解、字幕识别、发音评测分别选择服务；配置对应端点、模型和凭据 | 生成字幕、讲解、提交本次跟读评测 |
| 字幕 | 默认原文/双语显示、翻译语言、字号、自动滚动 | 临时切换字幕、定位当前句、调整本视频字幕偏移 |
| 影子跟读 | 默认语速、每句重复次数、句间停顿、跳过空白 | 开始练习、上一句/下一句、逐句复读、AB 区间、遮挡字幕 |
| 录音 | 输入设备、保存目录、录音后回放顺序 | 开始/停止录音、试听、重录、删除本次录音 |

建议默认值：双语、中文翻译、字号 18 px、自动滚动；跟读语速 1.0、每句重复 2 次、句间停顿 1 秒、跳过空白关闭；录音使用系统默认输入设备、先原声后录音回放。保存目录首次使用时明确选择。设备失效或目录不可写时提示错误，不静默更换。

录音与自动评测分开：录音保存在本地，用户触发评测时才上传当前录音片段。语音识别和发音评测使用不同的服务接口；文字模型用于解释评测结果，不作为发音评分来源。

## 先申请哪些服务

推荐先准备阿里云百炼和讯飞开放平台两个账号。以下是根据官方能力与本项目用途做出的选型建议，尚未在项目中完成接入或效果验证。

| 用途 | 建议服务或模型 | 需要准备 |
| --- | --- | --- |
| 翻译、词汇和语法讲解 | 阿里云百炼 `qwen-plus` | 百炼 API Key、地域、业务空间 ID |
| 没有字幕时生成带时间轴的字幕 | 阿里云百炼 `paraformer-v2` | 可访问该模型的百炼 API Key，与接入域名对应的地域及业务空间 |
| 英语跟读的发音评测 | 讯飞“语音评测（流式版）” | 对应服务的 APPID、APIKey、APISecret |

百炼可在同一地域和业务空间下给这两个模型授权同一个 Key；地域与接入域名不能混用。参见[获取 API Key](https://help.aliyun.com/zh/model-studio/get-api-key)与 [qwen-plus 模型说明](https://help.aliyun.com/zh/model-studio/qwen-plus)。

Paraformer 文件转写返回句子和词的开始、结束时间，适合转换为字幕时间轴。该接口接收可供服务读取的音视频 URL；本地文件的上传流程需要在接入时实现。参见[文件转写 REST API](https://help.aliyun.com/zh/model-studio/paraformer-recorded-speech-recognition-restful-api)。

讯飞需开通“语音评测（流式版）”的英文评测能力。其 WebSocket 接口要求音频为 16 kHz、16 bit、单声道，单次音频数据发送会话不超过 5 分钟；适合按句提交跟读片段。参见[讯飞语音评测文档](https://www.xfyun.cn/doc/Ise/IseAPI.html)。

如果已有 OpenAI API 账号，可另选 `gpt-4.1-mini` 做文字讲解、`whisper-1` 做带时间戳的转写。官方转写接口的 `timestamp_granularities[]` 仅适用于 `whisper-1`；接入时需按这一限制选模型。参见[文字模型](https://developers.openai.com/api/docs/models/gpt-4.1-mini)与[语音转写指南](https://developers.openai.com/api/docs/guides/speech-to-text)。无需同时申请所有方案。

已有 SRT/VTT 字幕的逐句复读、本地录音、原声对比均不需要模型 Key。第一阶段使用视频原声跟读，不需要申请语音合成服务。

## 后续实现顺序

1. 设置项及持久化：普通参数与密钥分开保存；密钥存储方案核验后再实现，界面不回显完整密钥。
2. 内置播放器读取 SRT/VTT，用播放器实际时间驱动字幕高亮、点句跳转、逐句复读和 AB 复读。
3. 本地录音与原声对比，再接入字幕识别、讲解和按句发音评测。

外部 MPV 的学习控制需要独立接入，不能将内置播放器能力直接视为 MPV 已支持。
