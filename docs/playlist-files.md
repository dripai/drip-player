# 播放列表文件操作

主界面、列表标题和列表项共用 `ContextMenu.vue`，使用当前主题和语言，支持方向键、Home/End、Escape、Tab，以及窗口边缘定位。页面菜单保留刷新和设置。

- **重命名**：名称与输入框同行，扩展名固定。修改磁盘文件名、媒体标题、下载任务输出路径；同目录内已关联且同名的字幕一起更名。媒体 ID 和学习记录保持不变，刷新列表后仍关联同一媒体。
- **从播放列表移除**：只移除列表成员，磁盘文件保留，下次目录刷新可重新出现。
- **删除**：确认弹窗显示实际文件名和完整路径，默认聚焦取消。确认后永久删除这一个媒体文件，同时移除列表成员、下载播放资源路径和任务中的输出路径；字幕、录音和学习数据保留。本地媒体保留历史 ID，但释放路径身份，同名新文件不会继承旧学习记录。

操作只接受当前目录中的普通文件。弹窗绑定列表成员、媒体 ID、目录版本、文件路径、大小和修改时间；确认前目录或文件已变化时要求重新操作。同媒体有活动或待恢复下载时拒绝操作；操作当前播放文件会停止该会话，其他媒体播放不受影响。录音未保存时前端阻止操作当前媒体。

文件操作与目录扫描、下载发布共用目录锁。重命名失败时回滚已经移动的文件，SQLite 事务不提交；回滚失败明确报告实际路径。永久删除先执行事务内 SQL，再删除文件并提交：SQL 或文件删除失败会回滚数据库；若文件删除后数据库提交失败，会明确提示文件已删除并要求重启、刷新，不能恢复已永久删除的文件。未提供跨进程崩溃的文件操作日志。

Windows 使用现有 `windows 0.62.2` 的 [`MoveFileExW`](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)，不开启覆盖标志，并保留文件属性；仅大小写更名经过同目录临时名称。标准库 [`rename`](https://doc.rust-lang.org/std/fs/fn.rename.html) 会覆盖已存在目标，因而不直接用于此处。其他桌面平台使用现有 `tempfile 3.27.0` 的 [`persist_noclobber`](https://docs.rs/tempfile/3.27.0/tempfile/struct.TempPath.html#method.persist_noclobber)，关闭自动清理并检查旧文件名是否遗留。

验证：临时目录与 SQLite 覆盖中文文件名、同名冲突、字幕联动、学习身份保留、目录切换、过期确认、下载记录同步、事务失败回滚，以及 Windows 文件占用和大小写更名。浏览器使用模拟 Tauri IPC 验证主题菜单、键盘操作、行内表单、删除确认及取消。原生 WebView2 播放中的文件操作和其他操作系统尚未实测。
